01гайд

Установка

От установки Rust до первого запуска голосового ввода.

Что понадобится

  • Windows 10/11, macOS 12+ или Linux с X11. Под Wayland глобальные хоткеи и вставка могут не работать.
  • Стабильный Rust (edition 2021) и инструменты сборки: MSVC на Windows, Xcode Command Line Tools на macOS, build-essential на Linux.
  • Микрофон.
  • Интернет и ~1.6 ГБ свободного места для однократной загрузки модели.
Особенности платформ

Windows: CUDA использует NVIDIA GPU; без него приложение автоматически работает на CPU.

macOS: только CPU. Разрешите доступ к микрофону и «Универсальный доступ» (Accessibility).

Linux: только CPU. Нужны системные библиотеки для аудио и GUI, глобальные хоткеи работают под X11.

1. Клонируйте репозиторий

git 
# 1. клонируем репозиторий
git clone https://github.com/Prog116/VoiceAI.git
cd VoiceAI

2. Создайте .env (необязательно)

Без .env приложение использует встроенные значения, а настройки можно менять прямо в интерфейсе — они сохранятся в .env автоматически.

3. Установите зависимости (Linux)

apt 
# 2. зависимости для Linux (Debian/Ubuntu)
sudo apt update
sudo apt install -y libasound2-dev libssl-dev libgtk-3-dev \
    libx11-dev libxkbcommon-dev libxkbcommon-x11-dev libxi-dev \
    libgl1-mesa-dev libwayland-dev

4. Соберите и запустите

cargo 
# 3. запуск с CUDA (Windows + NVIDIA)
cargo run --release --features cuda

# 4. CPU-сборка (Windows без NVIDIA, macOS, Linux)
cargo run --release

5. Разрешите доступ (macOS)

При первом запуске разрешите доступ к микрофону и «Универсальный доступ» (System Settings → Privacy & Security → Accessibility).

При первом запуске модель ~1.6 ГБ скачивается в фоне с Hugging Face в папку models/. После загрузки интернет не нужен.

02справочник

Настройка

Значения по умолчанию задаются через .env. Большинство настроек меняется прямо в интерфейсе и сохраняется автоматически.

Пример .env

.env 
# пример .env
HOTKEY_RECORD=F9
HOTKEY_EXIT=F12
RECORDING_MODE=hold
INPUT_DEVICE=
MIC_GAIN=10
FILLER_WORDS=эм,ну,как бы,типа,короче

Все переменные

Переменная По умолчанию Описание
WHISPER_MODEL_PATH models/ggml-large-v3-turbo.bin Путь к файлу модели .bin.
WHISPER_GPU auto auto / 1 / 0: использовать ли GPU в CUDA-сборке Windows (на macOS/Linux всегда CPU).
HOTKEY_RECORD F9 Клавиша записи; перезаписывается из интерфейса.
HOTKEY_EXIT F12 Клавиша выхода; перезаписывается из интерфейса.
RECORDING_MODE hold Режим записи: hold (Рация) или toggle (Переключатель).
INPUT_DEVICE — Имя входного устройства (микрофона); пусто — устройство по умолчанию.
MIC_GAIN 10 Усиление сигнала микрофона (1–50).
FILLER_WORDS эм,ну,как бы,типа,короче Список слов-паразитов через запятую для локальной очистки.
WORD_REPLACEMENTS см. ниже Замены слов, по одному правилу слово=замена на строку.

Замены слов по умолчанию

WORD_REPLACEMENTS 
дефис=-
двоеточие=:
точка с запятой=;
открывающая скобка=(
закрывающая скобка=)

Настройки интерфейса

  • Тема (тёмная/светлая) — для полного применения требуется перезапуск.
  • Входное устройство — выбор микрофона из списка; кнопка «Обновить» пересканирует устройства.
  • Усиление микрофона (1–50×) — применяется сразу; начните с 10–15×.
  • Режим записи — «Рация» или «Переключатель».
  • Горячие клавиши — назначаются нажатием и сохраняются в .env.
  • Путь к модели — можно выбрать файл кнопкой «Обзор»; после смены требуется перезапуск.
  • Стоп-слова и замены слов — редактируются в интерфейсе и сохраняются автоматически.

Изменённые настройки сохраняются в .env автоматически.

03гайд

Сборка

Релизная сборка и портативная версия для Windows.

Релизная сборка

Исполняемый файл появится в target/release/whisper_flow_rust (.exe на Windows).

cargo 
# Windows с NVIDIA GPU (CUDA)
cargo build --release --features cuda

# Windows без NVIDIA GPU, macOS, Linux (CPU)
cargo build --release

Портативная версия для Windows

CUDA-сборка зависит от cublas64_13.dll, cublasLt64_13.dll и Visual C++ runtime. package.ps1 собирает самодостаточный архив.

pwsh 
# полная сборка с CUDA
pwsh .\package.ps1

# лёгкая CPU-сборка без CUDA
pwsh .\package.ps1 -CpuOnly

Результат — папки dist\VoiceAI и dist\VoiceAI-cpu, а также архивы dist\VoiceAI-<версия>-win64.zip. CUDA-библиотеки берутся из установленного CUDA Toolkit.

# запуск тестов
