01Возможности

Всё, что нужно для диктовки

Горячая клавиша, голос и готовый текст в активном поле. Без облачных запросов, аккаунтов и подписок.

Полностью офлайн

Распознавание идёт через whisper.cpp. Модель лежит на диске, в облако не уходит ни байта.

local-first

Два режима записи

Удерживай F9, чтобы говорить, или включи режим переключения и нажимай один раз. Клавиша меняется в .env.

hold / toggle

Автовставка в любое поле

Готовая расшифровка вставляется через Ctrl+V (Cmd+V на macOS) в окно, которое было активно.

Ctrl+V / Cmd+V

GPU-ускорение

CUDA на Windows с NVIDIA и автоматический откат на CPU. macOS и Linux работают на процессоре.

CUDA · CPU

Чистка речи

Слова-паразиты и замена фраз на лету: например, произнесённые знаки превращаются в символы.

правила в .env

История и трей

Последние 2000 расшифровок хранятся локально в history.jsonl. На Windows есть иконка в трее.

history.jsonl

От голоса до готового текста в активном поле — пара секунд.

В любом приложении и любом поле. Удерживай клавишу или включи режим переключения.

Продиктуй

04CLI

Собирается из исходников

Проект написан на Rust. Клонируй, выбери бэкенд и запускай.

  • Rust-тулчейн (edition 2021)
  • CUDA Toolkit для GPU-сборки на Windows
  • Настройки в .env: клавиши, микрофон, режимы
  • package.ps1 собирает переносимую сборку для Windows
Открыть руководство по установке→
voiceai — shell 
# 1. клонируем репозиторий
git clone https://github.com/Prog116/VoiceAI.git
cd VoiceAI

# 2. запуск с CUDA (Windows + NVIDIA)
cargo run --release --features cuda

# 3. без GPU — CPU-сборка
cargo run --release

06FAQ

Частые вопросы

Короткие ответы перед установкой.

Нужен ли интернет?

Только чтобы скачать модель при первом запуске (~1.6 ГБ). Дальше распознавание работает полностью офлайн.

Где хранится история?

Локально в history.jsonl рядом с приложением, не больше 2000 записей. Никуда не отправляется.

Можно ли без GPU?

Да. На Windows приложение само откатывается на CPU, на macOS и Linux используется процессор.

Какие системы поддерживаются?

Windows 10/11, macOS 12+ и Linux с X11. На Wayland пока есть ограничения с глобальными горячими клавишами.

Куда уходит текст?

Никуда. Аудио и расшифровки остаются на твоей машине. Аккаунта и телеметрии нет.

Под какой лицензией проект?

BSD 3-Clause. Код можно использовать, изменять и распространять.
